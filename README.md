# Research data: equation-oriented decomposition paths

Selected recorded outcomes supporting the manuscript “Physics-Guided Discovery of Decomposition Paths for Initializing and Solving Equation-Oriented Process Models”.

- `classical_recovery.csv`: 168 classical path recovery cases.
- `identifier_neutralization.csv`: 23 identifier-neutralization cases.
- `weight_perturbations.csv`: recorded perturbation schedules and selected paths.
- `perturbation_trials_a.csv`, `perturbation_trials_b.csv`: separate trial records underlying the prescribed-interface perturbation study; these are not online-discovery runs.
- `online_discovery_summary.csv`: selected scalar fields from the online-discovery aggregate; large nested solver results and machine-specific file paths are omitted.

The perturbation strategy includes subsequent full-model refinement; final success is distinct from standalone outer closure. These files are a selected data release, not the complete model code, raw solver checkpoints, or full reproducibility package. Experimental protocols and limitations are described in the manuscript. `SHA256SUMS` identifies the released file bytes.
